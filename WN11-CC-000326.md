# STIG ID: WN11-CC-000326

## 🛡️ Vulnerability Overview
**Enable PowerShell Script Block Logging**

If Script Block Logging is not enabled, security teams lack visibility into the real code executed by PowerShell. Obfuscated scripts are commonly used by attackers to hide their actions. Enabling this feature causes Windows to log the de-obfuscated code during execution, offering critical telemetry for identifying "living-off-the-land" attacks.

---

## ⚙️ Remediation Approach

**PowerShell Implementation Logic:**
Via the Registry, the remediation script enforces a Group Policy setting to ensure logging is active across the system.

### Implementation Steps:

1.  **Path Validation:** The script navigates to `HKLM\SOFTWARE\Policies\Microsoft\Windows\PowerShell\ScriptBlockLogging`. If the key does not exist, the script creates it.
2.  **Enabling Logging:** It sets the `EnableScriptBlockLogging` DWORD value to `1`.
3.  **Result:** This forces the PowerShell engine to generate Event ID 4104 in the Event Viewer for all script blocks processed.
