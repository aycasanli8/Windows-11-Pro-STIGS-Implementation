# STIG ID: WN11-CC-000345

## 🛡️ Vulnerability Overview
**Disable Basic authentication for WinRM**

With Basic authentication, user credentials are sent across the network in a Base64-encoded form that can be easily reversed. An attacker who intercepts this traffic can quickly decode the credentials. Disabling Basic authentication ensures that more secure, encrypted protocols like Kerberos or Negotiate are used.

---

## ⚙️ Remediation Approach

**PowerShell Implementation Logic:**
By using the Group Policy Registry path, this remediation strictly enforces the setting at the policy level, taking precedence over local configurations.

### Implementation Steps:

1.  **Registry Targeting:** The script targets the specific policy key: `HKLM\SOFTWARE\Policies\Microsoft\Windows\WinRM\Service`.
2.  **Value Configuration:** It identifies or creates the DWORD value named `AllowBasic`.
3.  **Enforcement:** The script sets this value to `0`. This explicitly configures the Windows Remote Management service to reject any authentication attempts using the insecure "Basic" scheme.
