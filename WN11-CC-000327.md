# STIG ID: WN11-CC-000327

## 🛡️ Vulnerability Overview
**Enable PowerShell Transcription**

Logging captures individual commands, whereas Transcription generates a full text record of the PowerShell session, including all input and output. Failing to enable this feature leaves a gap in forensic visibility, complicating the reconstruction of an attacker's activity during an incident

---

## ⚙️ Remediation Approach

**PowerShell Implementation Logic:**
Via the Registry, the automation script activates system-wide transcription and configures a secure location for storing the transcripts.

### Implementation Steps:

1.  **Registry Configuration:** The script targets `HKLM\SOFTWARE\Policies\Microsoft\Windows\PowerShell\Transcription`.
2.  **Activation:** It sets the `EnableTranscripting` DWORD value to `1`.
3.  **Output Definition (Optional but Recommended):** The script may also configure the `OutputDirectory` string to ensure logs are saved to a hardened, monitored directory rather than the user's default documents folder.
