# STIG ID: WN11-CC-000038

## 🛡️ Vulnerability Overview
**Disable WDigest authentication**

WDigest (Windows Digest) authentication is an legacy protocol that retains credentials in plaintext within the Local Security Authority Subsystem Service (LSASS) memory. When enabled, an attacker with local administrator privileges can harvest these credentials using tools like Mimikatz, potentially leading to credential compromise and lateral movement within the network.

---

## ⚙️ Remediation Approach

**PowerShell Implementation Logic:**
To remediate this vulnerability, the automation script modifies the Windows Registry to enforce the required security provider settings.

### Implementation Steps:

1.  **Registry Targeting:** The script locates the path `HKLM\SYSTEM\CurrentControlSet\Control\SecurityProviders\WDigest`.
2.  **Value Enforcement:** It checks for the registry value `UseLogonCredential`.
3.  **Modification:** The script sets this DWORD value to `0`. This explicitly tells Windows not to store credentials in memory for WDigest, effectively neutralizing the vector for memory scraping attacks.
