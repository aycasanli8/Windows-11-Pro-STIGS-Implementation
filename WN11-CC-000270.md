# STIG ID: WN11-CC-000270

## 🛡️ Vulnerability Overview
**Prevent RDP client from saving passwords**

When a user saves credentials in the Remote Desktop Connection client, they are stored on the local disk. If an attacker gains access to the machine, they can harvest these saved credentials to move laterally to other servers without requiring password cracking.

---

## ⚙️ Remediation Approach

**PowerShell Implementation Logic:**
The script uses the Registry to enforce a Group Policy restriction that disables the "Save Credentials" checkbox in RDP

### Implementation Steps

1.  **Registry Key Check:** The script looks for `HKLM\SOFTWARE\Policies\Microsoft\Windows NT\Terminal Services`. It creates the key if missing.
2.  **Policy Application:** It targets the value `DisablePasswordSaving`.
3.  **Modification:** The script sets this DWORD to `1`. This greys out the option to save passwords in the RDP client UI and prevents the underlying functionality.
