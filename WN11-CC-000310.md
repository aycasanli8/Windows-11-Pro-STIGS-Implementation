# STIG ID: WN11-CC-000310

## 🛡️ Vulnerability Overview
**Restrict users from altering installation settings.**

Allowing users to adjust installation settings, including location, features, or administrative privileges, during software installation may bypass security controls, providing an opportunity for malware or malicious insiders to deploy software in unauthorized directories or with unsafe configurations.

---

## ⚙️ Remediation Approach

**PowerShell Implementation Logic:**
The script restricts Windows Installer behavior by configuring the Registry.

### Implementation Steps:

1.  **Registry Targeting:** The script navigates to `HKLM\Software\Policies\Microsoft\Windows\Installer`.
2.  **Control Restriction:** It targets the `EnableUserControl` value.
3.  **Modification:** The script sets this DWORD to `0`. This restricts the Windows Installer, preventing users from changing install parameters and forcing the installer to use the default, admin-approved settings.
